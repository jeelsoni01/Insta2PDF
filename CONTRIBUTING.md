# Contributing to Insta2PDF

First off — thanks for even being here. Every contribution matters, big or small.

---

## Anyone can contribute

You don't need to ask permission. If you see something broken, something missing, or something that could be better — just go for it. Open an issue, send a PR, or suggest an idea. All of it is welcome.

---

## How to contribute

1. **Fork** the repo
2. **Create a branch** for your change
   ```
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** and test them in Chrome or Edge
4. **Commit** with a clear message
   ```
   git commit -m "What you changed and why"
   ```
5. **Push** and open a Pull Request
   ```
   git push origin feature/your-feature-name
   ```

---

## What you can work on

- Bug fixes
- New features or ideas
- Better error messages
- UI improvements to the popup
- Documentation improvements
- Anything else you think would help

No task is too small. Fixing a typo is a valid contribution.

---

## The only real rule

Test your change in Chrome or Edge before submitting. The extension must work with Manifest V3. That's it.

---

## Opening an issue

If you find a bug or have a feature idea but don't want to code it yourself, open an issue. Describe what you saw, what you expected, and steps to reproduce if it's a bug.

---

## Questions?

Open an issue and ask. No question is too basic.
